# Dusk Highway

A 3D driving game in a single HTML file (`index.html`), built with three.js.

- **Steer**: tilt the phone like a steering wheel, or turn the on-screen wheel. Arrow keys / WASD on a keyboard.
- **Pedals**: hold Gas and Brake. **Nitro** (Shift) boosts, **Horn** (H) moves traffic over, **View** (C) switches camera.
- **Garage**: eleven original cars with different speed, pickup, handling and strength, bought with coins; eight paints.
- **Stages**: every 800 m the time of day changes (dusk, night, rain, dawn) and traffic gets busier.
- **Damage**: scrapes and bumps wear the car down; the run ends when its condition reaches zero.

Tilt steering needs the page served over HTTPS (for example GitHub Pages) and opened directly
in the phone's browser; allow motion access if the browser asks. Tilt sensitivity and
direction can be changed in the garage.
