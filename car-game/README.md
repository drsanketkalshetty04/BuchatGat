# Dusk Highway

A 3D tilt-to-steer driving game in a single HTML file (`index.html`), built with three.js.

- **Steer**: tilt the phone like a steering wheel, or drag the on-screen wheel. Arrow keys / WASD on a keyboard.
- **Pedals**: hold Gas and Brake.
- **Score**: 1 point per metre, +50 for each close pass. One crash ends the run.

Tilt steering needs the page to be served over HTTPS (for example GitHub Pages) and opened
in the phone's browser; on iPhone, allow "Motion & Orientation" when asked.
